# \## 🔴 Important Changes

# 1\. \*\*Corrected the Maxwell locating point structure\*\*

# For the original structure: under high-flow conditions, the locating point would slip, directly affecting print accuracy. It has now been adjusted so that \*\*the greater the extrusion amount, the tighter the clamping\*\*. Even if the extruder skips steps, the toolhead will not slip, greatly improving positioning reliability.

# 2\. \*\*Replaced square nuts with heat-set inserts\*\*

# The original solution used square nuts, which tended to loosen after long-term use; they have been changed to heat-set inserts to improve the long-term stability.
